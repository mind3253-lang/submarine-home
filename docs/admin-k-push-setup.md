# K방 갤럭시 웹 푸시 운영 설정

## 현재 상태
- `admin-k-mobile.html`: 관리자 결제요청 목록/승인, 기기별 푸시 등록, 테스트 버튼
- `admin-k-sw.js`: 푸시 수신 및 알림 클릭 시 K방 열기
- `worker.js`: 관리자 인증 후 구독 등록/삭제, 테스트 발송, 현금결제 요청 시 발송
- 실제 도메인 배포, 비밀키 설정, 기기별 수신 검증은 별도 필요

## 서버 설정
Worker 환경변수/시크릿:
- `VAPID_PUBLIC_KEY`: P-256 공개키 (비압축 65바이트, base64url)
- `VAPID_PRIVATE_KEY`: 같은 키 쌍의 PKCS#8 DER 개인키를 base64url 인코딩한 값. **시크릿으로만 저장**
- `VAPID_SUBJECT`: 운영 연락처 `mailto:admin@example.com` 형식

개인키를 GitHub, 브라우저 소스, 채팅, 문서에 붙여넣지 않는다.
키를 생성할 때 반드시 공개키/개인키가 같은 P-256 키 쌍인지 검증한다.

## 설치 및 테스트
1. HTTPS 도메인에 Worker/정적 파일이 실제 배포됐는지 확인.
2. 갤럭시 크롬 또는 삼성 인터넷에서 `https://submarine.asia/admin-k-mobile.html` 열기.
3. 관리자 로그인 후 `이 휴대폰 푸시 알림 등록`을 누르고 알림 허용.
4. 사모님 휴대폰에서도 별도로 반복.
5. `테스트 푸시 발송`을 눌러 **두 휴대폰 모두** 화면이 꺼진 상태에서 수신 확인.
6. 테스트 회원으로 결제요청 1건 등록, 알림 수신, 실제 입금확인 후 한 번만 승인되는지 확인.

## 유의사항
- 웹 푸시 수신은 운영체제/브라우저의 알림 설정, 절전 정책, 네트워크 상태에 따라 지연될 수 있음.
- 기존 관리자 페이지 바로가기와 `admin-k-mobile.html`은 다른 진입 경로.
- 기존 결제 승인 API는 공유하므로 중복 승인/동시 승인에 대한 원자성 테스트가 필요함.
- 현재 구독 저장은 단일 JSON 객체를 읽고 덮어쓰는 방식이므로 동시 등록 시 갱신 충돌 가능성 있음. 운영 규모 확대 시 트랜잭션 가능한 저장소 권장.
- 테스트 엔드포인트는 실제 발송 성공/수신을 보증하지 않고 발송 시도만 반환함.
