# SUBMARINE iOS wrapper

Bundle ID: `asia.submarine.app`
App name: `SUBMARINE`
Production URL: `https://submarine.asia`

This Capacitor project wraps the existing production site for iOS. The native iOS project is generated during the macOS build step with `npm ci && npx cap add ios && npx cap sync ios`.

App Store review note: before submission, verify native navigation, external links, file/photo upload, authentication, payment flows, safe-area layout, offline/error handling, and add native value where required by App Review.
